# Business Error 
 ## UI Display rules -
 - For all business error codes, display the error message in a user-friendly manner, at the top of the page, in a red alert box. The error message should be clear and concise, indicating the specific issue that occurred.
 - If the error code is not recognized, display a generic error message: "An unexpected error
  occurred. Please try again later." 
- 80201: 
  - Business name already exists. This error is thrown when trying to create a new business with a name that already exists in the system.
- 80202: 
  - Package name already exists. This error is thrown when trying to create a new package with a name that already exists in the system.  
- 80199 :
  - Something went wrong, please try again later!.
